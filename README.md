# 🎓 StudentSphere — Student Management ERP System

A full-stack **MERN** (MongoDB, Express.js, React, Node.js) based Student Management ERP platform with role-based dashboards for **Students**, **Teachers**, and **Admins**.

---

## ✨ Features

### 🔐 Authentication & Security

- JWT Authentication
- Protected Routes
- bcrypt password hashing
- Role-based access control

### 👨‍💼 Admin Dashboard

- Manage Students
- Manage Teachers
- Department Management
- Attendance Logs
- Dashboard Statistics

### 👨‍🏫 Teacher Dashboard

- Mark Attendance
- Upload Results
- Create Assignments
- Compare Students
- Leave Management

### 👨‍🎓 Student Dashboard

- View Results
- Attendance Tracking
- Apply for Leave
- Profile Management
- Smart Suggestions

---

## 🛠️ Tech Stack

| Layer | Technology |
|-------|------------|
| Frontend | React.js, Tailwind CSS |
| Backend | Node.js, Express.js |
| Database | MongoDB Atlas |
| Authentication | JWT, bcrypt |
| Charts | Recharts |
| Real-time | Socket.io |

## 🚀 Getting Started

### Clone Repository

```bash
git clone https://github.com/sharmarakshitdei-spec/StudentSphere.git
```

### Install Backend

```bash
cd server
npm install
npm run dev
```

### Install Frontend

```bash
cd client
npm install
npm run dev
```
